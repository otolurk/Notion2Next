## 关于本仓库

本仓库**仅保留了 `endspace` 主题**，并针对个人需求进行了大量适配改造，包括：

- 全站日间 / 夜间双套配色方案
- 准星光标、封面加载失败占位、字体自托管（狸叶黑体）等细节定制

**您可以前往 [ototime.top](https://www.ototime.top/) 体验。**
